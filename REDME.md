# Sistema Administrativo de Cadastro de Membros

Sistema web desenvolvido para gerenciamento e cadastro administrativo de membros de igreja.

O projeto foi criado com foco em usabilidade, responsividade e integração simples com Google Sheets, permitindo armazenar os dados de forma online sem necessidade de banco de dados tradicional.

## Funcionalidades

- Cadastro completo de membros
- Validação de CPF
- Bloqueio de CPF duplicado
- Máscaras automáticas
- Layout responsivo
- Integração com Google Sheets
- Feedback visual de sucesso e erro
- Validação de campos
- Controle de aceite de uso de dados

## Campos do Cadastro

- Nome completo
- Data de nascimento
- CPF
- Tempo de batismo
- Contato
- Cidade
- Estado
- Porte da igreja
- Sede responsável
- Endereço da igreja
- Pastor responsável
- Código da igreja

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets

## Objetivo

O sistema foi desenvolvido para uso administrativo interno, permitindo centralizar o cadastro de membros de forma simples, acessível e online.

## Responsividade

O projeto possui adaptação para:
- Desktop
- Tablets
- Smartphones
